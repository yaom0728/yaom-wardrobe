# 야옴 옷장

BOOTH 구매 라이브러리를 분류해서 보는 개인 정적 사이트입니다.

## GitHub Pages

저장소 Settings → Pages에서 `Deploy from a branch`, `main / root`를 선택하면 배포됩니다.

`app.js`의 `STATUS`에 상품 ID와 상태를 추가하면 판매 종료·샵 폐쇄 배지가 표시됩니다.

## 상품 공개 설정

관리자 화면에서 상품 카드의 **공개 설정**을 선택하고 **설정 저장**을 누릅니다.
비공개 상품은 공개 목록, 검색, 카테고리/즐겨찾기/기프트 수 및 판매자/아바타 필터에서 제외됩니다.
관리자 화면에서는 비공개 상품도 조회하고 다시 공개할 수 있습니다.

설정은 `collections.json`의 `hiddenItems`에 BOOTH 상품 ID 문자열 배열로 저장됩니다.
필드가 없으면 모든 상품은 공개입니다. 기존 카테고리/사용자 컬렉션 설정과 호환됩니다.
자동 동기화는 `data.js`와 `index.html`만 갱신하므로 공개 여부는 유지됩니다.

이는 **공개 화면에서 숨기기** 기능입니다. 상품 데이터와 설정, Git 과거 기록은 여전히 공개될 수 있으며 접근 제어/비밀 저장 기능이 아닙니다.
